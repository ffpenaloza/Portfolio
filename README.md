## Data Science

### [Churn Prediction](https://github.com/ffpenaloza/data-science-training/tree/main/Coursera%20-%20Churn%20Challenge)

Proyecto de predicción de abandono de clientes (*churn*) para un servicio de streaming, desarrollado en el contexto de un challenge de Coursera.

El trabajo incluye exploración y preparación de datos, ingeniería de características, transformaciones de variables, separación de datos para entrenamiento y validación y construcción de un modelo de regresión logística.

El modelo obtuvo un **ROC-AUC de 0,7541** en el conjunto de validación. En la evaluación del challenge, el resultado obtenido fue de **75,09 %**, ubicándose en el **percentil 99** entre los participantes al momento de la consulta.

**Tecnologías:** Python · Jupyter Notebook · Pandas · NumPy · Scikit-learn · Matplotlib · Seaborn

**[Ver notebook →](https://github.com/ffpenaloza/data-science-training/blob/main/Coursera%20-%20Churn%20Challenge/ChurnPrediction.ipynb)**

**[Ver en Coursera Lab](https://hub.labs.coursera.org/connect/sharedoigfwpjj?forceRefresh=false&path=%2Fnotebooks%2FChurnPrediction.ipynb&sessionMigrationMode=shadow)**

## Desarrollo Web

### [https://auto.calistoweb.cl](https://auto.calistoweb.cl)

Plataforma para consultar información histórica de revisiones técnicas de vehículos en Chile.

El servicio utiliza el [PRT Data Pipeline](./prt-loader/) para procesar y cargar los datos utilizados por la plataforma.

**Tecnologías:** Python · MySQL · PHP · CodeIgniter · procesamiento de datos · automatización

### [LetrasChile](https://letraschile.com)

Sitio web de letras de canciones chilenas, desarrollado y administrado de forma independiente. Permite el registro y contribución de usuarios para el crecimiento de la base de datos.

Ejecuta una automatización para publicar en Instagram, X, TikTok y Threads una "Canción del día" y un fragmento de esa canción. Para cada publicación se escoge un fragmento y se genera una reflexión mediante inteligencia artificial, también de manera automatizada.

El resultado puede verse en el [Instagram de LetrasChile](https://www.instagram.com/letraschile).

**Tecnologías:** PHP · CodeIgniter · MySQL · APIs · Automatización

### [ClaseKit](https://clasekit.cl)

Aplicación orientada a docentes para la gestión de grupos, actividades y otras tareas administrativas.

En desarrollo temprano.

**Tecnologías:** Vue · TypeScript · Vite · Tailwind CSS · Supabase (en desarrollo) · Cloudflare

### [Punto de Mira](https://puntodemira.cl)

Sitio web de la banda chilena Punto de Mira, desarrollado como CalistoWeb SpA y orientado a la presentación del proyecto musical.

**Tecnologías:** Nuxt · Vue · TypeScript · Tailwind CSS
