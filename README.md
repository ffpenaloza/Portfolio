# Fernando Peñaloza Garrido

Portfolio de proyectos de **Data Science, Data Engineering, desarrollo de software, procesamiento de datos y automatización**.

## Proyectos

### [PRT Data Pipeline](./prt-loader/)

**Tipo:** Data Engineering · ETL

Pipeline para descargar, transformar y cargar datos históricos de Plantas de Revisión Técnica (PRT) de Chile.

Alimenta el servicio [Auto CalistoWeb](https://auto.calistoweb.cl).

**Tecnologías:** Python · Pandas · OpenPyXL · MySQL · SSH/SCP

### [Auto CalistoWeb](https://auto.calistoweb.cl)

**Tipo:** Aplicación web · Datos

Plataforma para consultar información histórica de revisiones técnicas de vehículos en Chile.

**Tecnologías:** Python · MySQL · PHP · CodeIgniter · procesamiento de datos · automatización

### [LetrasChile](https://letraschile.com)

**Tipo:** Aplicación web · Automatización

Sitio web de letras de canciones chilenas, desarrollado y administrado de forma independiente. Permite el registro y contribución de usuarios para el crecimiento de la base de datos.

Ejecuta una automatización para publicar en Instagram, X, TikTok y Threads una "Canción del día" y un fragmento de esa canción. Para cada publicación se escoge un fragmento y se genera una reflexión mediante inteligencia artificial, también de manera automatizada.

El resultado puede verse en el [Instagram de LetrasChile](https://www.instagram.com/letraschile).

**Tecnologías:** PHP · CodeIgniter · MySQL · APIs · Automatización

### [ClaseKit](https://clasekit.cl)

**Tipo:** Aplicación web · EdTech

Aplicación orientada a docentes para la gestión de grupos, actividades y otras tareas administrativas.

En desarrollo temprano.

**Tecnologías:** Vue · TypeScript · Vite · Tailwind CSS · Supabase (en desarrollo) · Cloudflare

### [Punto de Mira](https://puntodemira.cl)

**Tipo:** Sitio web · Proyecto para terceros

Sitio web de la banda chilena Punto de Mira, desarrollado como CalistoWeb SpA y orientado a la presentación del proyecto musical.

**Tecnologías:** Nuxt · Vue · TypeScript · Tailwind CSS
